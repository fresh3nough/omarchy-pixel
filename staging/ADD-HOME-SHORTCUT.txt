Omarchy home shortcut (Pixel)

Preferred:
  1. App drawer → long-press "Omarchy" → Add to Home
  2. Place the icon on homescreen page 2
  3. Tap once → launches Termux:X11 Omarchy desktop (sway + foot + waybar + goose)

Alternate (Termux:Widget):
  1. Long-press home → Widgets → Termux:Widget → Omarchy
  2. Same fullscreen session via start-omarchy-fullscreen.sh

Automatic boot:
  ~/.termux/boot/00-omarchy.sh starts the session after Android boot.

Binds:
  Super+Return Foot | Super+G Goose Desktop | Super+Shift+G goose CLI
  Super+B Chromium | Super+P 1Password | Super+F Fullscreen
